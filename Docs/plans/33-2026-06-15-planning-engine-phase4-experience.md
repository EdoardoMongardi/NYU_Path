## Methodology & verification gates

**Subagent-driven TDD** (`superpowers:subagent-driven-development`). Fresh implementer per task → spec review → code-quality review → fix loop. **RED before GREEN:** write the failing test named in each task FIRST, watch it fail for the right reason, then implement the seam.

**Per-task gates (ALL must pass before the task's commit):**
- Full `vitest` suite green at the **repo root** (`npx vitest run`) — the touched package + any dependent package. (Operator-gated / live-DB tests run on demand, not in the default CI suite: E6.5 and E6.6 are `skipIf(!DATABASE_URL)`.)
- `tsc --noEmit` clean, run **3×** (catches incremental-cache flakiness), for **each touched package** — Phase 4 touches `apps/web`, so run **`cd apps/web && npx tsc --noEmit` 3×** (and `cd packages/engine && npx tsc --noEmit` 3× if engine types are touched). **NEVER `tsc -b`** (it emits `.js` shadows that vitest then runs instead of the `.ts`).
- **0 `.js` shadows** in `src/` / `app/` (no stray compiled output committed).
- **Scoped commit:** `git add <explicit files>` — **NEVER `git add -A`**. Message trailer:
  `Co-Authored-By: Claude Opus 4.8 (1M context) <noreply@anthropic.com>`
- **Preserve the pre-existing working-tree leftovers** — do NOT touch or revert: deleted `.agent/rules/00-implementation-guardrails.md`, modified `pnpm-lock.yaml`, untracked `packages/engine/scripts/diagnoseInfeasible.ts` + `tools/bulletin-parser/validateCurated.ts`.
- **Branch off `main`** for the work. **Do NOT push or merge unless explicitly asked.** The repo is PRIVATE — do NOT flip it public (PII-GC blocker is owner-only).
- **Validity-is-a-contract holds on every edit path** — confirm no task introduces a bypass apply: every add/drop/swap/move/preview routes through the existing `finalizeForwardSchedule` + 7-axis `runGraduationPathValidator` (§11).
